# 单机版 v2.5.7 ↔ 联机引擎 base-online-v3 规则差异清单

> 更新：2026-08-12 · 依据：仓库当前单机版 `合掌网页版v2.5.7` 与最新统一规则 vs 联机引擎 `hermes-hezhang/src/rules.mjs`
> 用途：交单机版作者（规则权威）逐项核对迁移；交联机运维侧做回归口径对齐。
> 结论先行：**结果无重大规则冲突**；差异集中在"未实现特性"与"数值/交互颗粒度"。

---

## 0. 总述

单机版 v2.5.7 是**完整规则全集**（36 技能 + 剪刀 + 帮接帮闪 + 主动承受 + 月亮防反 + 怪兽猜拳 + 魔术师 + 审判/渔夫 + 秘偶/龙护盾链）。普通攻击允许帮助赌博：不帮时接／闪保护自己，帮助时放弃自我保护；极光复制攻击禁止帮接／帮闪，但仍允许主动承受。
联机引擎 base-online-v3 是**双人可玩子集**（基础行动 + 可选剪刀 + 四属性 + 确定性结算）。
两者在"已共同实现的部分"上**行为一致**（经实测：同级攻击互不受伤、等级压制、护盾挡一次、重开清锻均吻合）。
真正的差异 = 联机尚未实现的功能面 + 实现范式差异。

## 2. 数值体系差异

| 维度 | 单机版 | 联机 | 差异 |
|---|---|---|---|
| 生命 | 支持 0.5 增量（母亲/圣斗士/观者/渔夫/牧羊人） | 整数 HP | 联机四属性为整数，迁移需支持 0.5 单位或取整策略 |
| 攻击力 | 支持 0.5（观者/渔夫初始 0.5 攻） | 整数 0-10 | 同上 |
| 锻数 | 无上限 | 初始 0-10，运行无上限 | 规则一致（锻不设上限） |
| 护盾 | 本体盾 + **龙盾 + 秘偶盾**，承伤顺序：秘偶→龙→护盾→本体 | 仅本体盾（挡一次任意非真实伤害） | 联机缺承伤物体系 |
| 真实伤害 | 太阳全伤真伤、猎人死亡真伤 | ❌ 无真伤概念 | 联机护盾可挡一切；迁移太阳/猎人需引入真伤标志（绕盾） |
| 伤害修正 | 观者 ±0.5、易伤、牧羊人减伤、暴君 10 伤、死神成长 | 无 | 技能体系附带 |

## 4. 多人规则差异（联机多人未开放，但判刀基础已备）

| 特性 | 单机版（真人 vs AI 多人） | 联机引擎（多人逻辑） |
|---|---|---|
| 逐级判刀/防御等级 | ✅ | ✅ 已实现 |
| 3 级以上抵刀 | ✅ | ✅ 已实现 |
| 每回合一次命中上限 | ✅ | ✅ 已实现 |
| 帮接/帮闪 | ✅ 不帮则本人安全、其余角色判刀；帮则当前刀无人受伤并统一重开，但放弃自保；极光禁止 | ❌ 尚无多人交互协议 |
| 主动承受（“帮”） | ✅ 命中前选择，选中即占用判刀名额 | ❌ 无 |
| 虚无多目标刀 | ✅ | ✅ 已实现 |
| 极光多目标 | ✅ | ❌ 技能缺失 |
| 奇迹宣言 | ✅ | ❌ |
| 怪兽拦截/猜拳 | ✅ | ❌ |
| 魔术师链 | ✅ | ❌ |
| 渔夫挑战 | ✅ 无技能追加对局 | ❌ |
| 月亮防反（多人） | ✅ 最高防御优先级 | ❌ |

**迁移要点**：多人帮助需要真人交互——普通攻击应在随机判刀前秘密询问有效接／闪使用者是否帮助；不帮者本人退出本刀可命中范围，其余未受保护者继续判刀；有人帮助则当前刀完整防住、无人受伤并记录统一重开，同时帮助者失去本次出手自我保护。极光复制攻击跳过帮接／帮闪询问。若未被帮防，再向具备资格者询问是否主动承受；被选中者立即占用本回合唯一判刀名额。

## 5. 实现范式差异（迁移必读）

| 维度 | 单机版 | 联机 | 迁移影响 |
|---|---|---|---|
| 随机数 | `Math.random()` | **种子 RNG**（SHA-256 种子，可复算） | 技能中随机判定（判刀目标、猜拳顺序）需改为种子 RNG 或真人选择；否则失去确定性 |
| 结算 | 异步交互式（await 玩家选择） | 同步函数 `resolveStep` | 带真人交互的技能（怪兽猜拳、魔术师、主动承受、猎人死亡选人）无法在单次 submit 内完成——需**回合外交互协议**（先暂停结算 → 私聊询问 → 收集答复 → 再结算） |
| 状态模型 | 双人 state.player/state.ai + 多人 mpState | 房间数组 players | 技能字段（roundFlags/defenseQuota/judgementHitThisRound 等）需平移到玩家对象 |
| 事件分发 | SkillTiming 管道（before-monster/after-monster/before-damage/damage-dealt…） | 线性 resolveStep | 技能迁移建议引入最小事件钩子（on-hit / on-damage / on-death / on-round-end） |

## 6. 联机引擎独有（单机版没有）的工程特性

- 网络房间/队伍/QQ openid 身份
- 状态落盘可恢复（单机版刷新即重置）
- 确定性可复算结算（可仲裁/回放）
- 战斗记录导出（`/记录`）
- 四属性建房配置（单机版固定角色属性）

## 7. 迁移优先级建议（给接手 AI 的行动清单）

### 第一批（无交互被动，零交互改造）
1. 死神（造成伤害 +1 血 +1 攻）——需 on-damage 钩子
2. 暴君（hp≤1 时伤害=10）——需 damage 修正钩子
3. 太阳（伤害全真伤）——需真伤标志
4. 战士（武士刀破防 0.5 伤）——需完整0.5体系，不得临时取整改变规则
5. 刺客（小刀首命 +0.5；防可挡手里剑）——需 0.5 + 防扩展

### 第二批（轻交互）
7. 守卫（防/接获得 0.25/0.5 锻）——需 0.5 锻或乘 4 整数化
8. 壁垒（大盾 1 锻防除虚无外攻击）——新行动键
9. 白塔（首次武器返还花费）
10. 窥秘人/囚徒（费用修正类）

### 第三批（重交互，需设计 QQ 回合制交互协议）
11. 猎人（死亡后由猎人本人当场选人）——需 on-death 钩子、真伤标志与暂停结算选择协议
12. 怪兽猜拳 / 魔术师改写 / 审判追加 / 渔夫挑战 / 黑皇帝护盾转移 / 占卜家秘偶 / 龙骑士
13. ~~剪刀模式（行动表 + 克制 + 网关别名）~~——已在`base-online-v3`完成

### 第四批（多人开放）
14. 解除 duo 锁定（teams 2-6 / 每队 1-4 / ≤12 人）
15. 主动承受交互协议（作用对象确定前私聊询问，选中后立即消耗判刀名额）
16. 多人技能（极光/观众/黑夜/牧羊人等领域类；极光复制攻击不得预设目标）
