# 手势游戏-合掌
合掌（The Clap） 是一款源于中国某重点高中的手势策略游戏，融合了资源分配与实时博弈，能有效锻炼玩家的瞬时反应力和短期记忆力。 本仓库提供了完整的 HTML 游戏实现，支持 单人挑战一个或多个 AI 对手，并内置进阶玩法 —— 「技能」系统。 同时，仓库中附带了一份详细的游戏规则说明（DOCX 格式），方便您快速上手和自定义扩展。
