规则来源：`docs/rules/sources/合掌技能版（第三版）.docx`。
实现基线：本地 `合掌网页版-正式版本存档/合掌网页版v2.5.7.html`。

新版本仍为可直接离线打开的单 HTML，保留 v2.5.7 原文件。第二版统一规则的 DOCX/Markdown 不在本次修改范围；第三版原文及沿用的基础判刀说明独立保存为 `docs/rules/releases/合掌v2.5.8规则.md`，与新 HTML 内置规则完全一致。

## 主要变化

| 角色 | 第三版调整 |
| --- | --- |
| 通识者 | 连续锻造时本次获得2锻；受击锻造仍不获得能量。 |
| 死神 | 初始2血0攻；命中触发生命和攻击成长，零伤害或被护盾挡住仍算命中。 |
| 暴君 | 新增每轮两次记录生命、降至1血，并在次回合结束恢复记录值的主动技能。 |
| 审判者 | 初始2血；本回合有伤害时，在回合结束选择无技能对局，获胜再造成一次技能伤害。 |
| 战士、刺客、窥秘人 | 战士破防为0.5真实伤害；刺客小刀增伤可选择是否发动；窥秘人的龙牙、虚无必定命中。 |
| 观众 | 移除旧2锻退场行动；非小刀命中后可携带至多2人退场，无在场队友的退场者受到真实伤害。 |
| 黑夜 | 移除回溯；开局指定角色失去被动，主动和领域独立判断。 |
| 太阳 | 领域直接禁止敌方选择指定攻击，移除旧回合末追伤。 |
| 学徒 | 改为命中时获得尚未拥有的剩余技能，不再因已拥有技能回血；复制保留已消耗次数。 |
| 占卜家 | 死亡换偶仅由友方角色死亡触发。 |
| 守卫 | 防、接均获得0.25锻，闪花费减1。 |
| 壁垒 | 大盾本回合首次2锻，此后0锻；移除旧援护领域。 |
| 观者 | 初始2血1攻、平静；接获得1锻并进入暴怒，攻击造成和承受倍率随状态变化。 |
| 渔夫 | 无须鱼钩或自损；挑战其他角色的主动技能，获胜令该技能失效并造成1伤害。 |
| 圣斗士 | 失盾时可积累下次伤害+0.5，移除旧伤害后回血效果。 |
| 奇点 | 易伤每回合开始可发动一次，领域每轮两次。 |
| 牧羊人 | 补次数包含领域等有限次数效果。 |
| 苦修 | 新角色：阻止生命增加；每轮一次可防止致命伤害。 |
| 暗影 | 新角色：猜拳视为获胜；非攻击命中造成的死亡调整为1血。 |

双人、多人和 AI 的技能入口同步更新；无技能双人继续使用独立基础引擎。另修复无技能攻击战报访问技能专属状态、盗贼临时技能过早结束、风暴1.5级对接闪判定等相关回归问题。

## 保留的数字化边界

- 第三版未明确推翻基础抵刀优先级，因此窥秘“必定命中”仍不越过既有同级抵刀规则。若规则制定者希望必定命中也取消抵刀，需要另行裁定。
- “0到1内”的低血量死亡沿用旧版 `0 < 血量 < 1`，恰好1血不触发。
- 观众在命中响应后立即标记退场，不能发动技能或成为后续判刀目标；退场持续至下一完整回合结束。已建立的攻击仍按旧版同时出手规则完成。若场上暂时不足两个在场阵营，自动结束空回合并使角色返回，避免无法继续操作。
- 以上是本次兼容实现的边界，不替代规则原典；其中退场跨回合范围及窥秘与抵刀的优先级仍可由规则制定者进一步明确。
