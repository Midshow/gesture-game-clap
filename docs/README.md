## 作者文章合集

`rules/sources/龚君文集（部分）.docx` 为维护者手动复制的知乎文章选集。已阅读本地正文，尚未核验线上全文，包含五篇：

- 《可观测宇宙合掌群史》：记录2026年4月至8月的群体发展、技能版传播、网页开发与博弈研究。
- 《合掌学1:合掌学的研究方法》：区分统计实验与理论分析，讨论经典双人最优出招问题。
- 《合掌学2:统计合掌学参数（1）》：介绍血量—攻击模型、胜负及单局胜率参数。
- 《线下合掌的实现方法》：介绍手势动作和用猜拳实现随机判定的办法。
- 《合掌规则 2026.8.5》：介绍经典招式、攻防等级、重开、判刀与抵刀。

该合集属于历史、教学和研究参考，不因暂存于 sources 就自动覆盖原典或当前技能第三版。文中的“彻底解决最优出招”等表述是文章观点，不能代替对研究假设、证明和计算结果的独立核验。文内维护者注解也应与文章正文区分引用。

阅读时需注意：

- 抵刀条款写攻击等级“大于3”，后文仅讨论“小于3”，未明确恰好3级；现有数字实现采用三级及以上抵刀，需结合统一规则与已有裁定理解。
- “每位合掌者至多受到1点伤害”不能直接推广为技能版伤害上限；当前实现区分一次命中资格与实际伤害量。
- 锻造时任何攻击都能“秒你”是基础一命场景的通俗说明，不能覆盖技能版血量、护盾及免死机制。
- 随机判定段落对有利结果和受伤者均使用“通常有利”的措辞，疑似笔误；线下多轮猜拳与中途请求帮助的流程不能未经裁定直接等同于网页随机判刀。

以上仅记录阅读发现，未据此修改游戏结算或原始文档。
