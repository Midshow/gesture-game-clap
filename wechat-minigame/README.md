# 合掌 v2.5.8.2 微信小程序测试版

AppID：`wx01fee00acfaa4d5e`，项目类型为 **miniprogram**。目录名 `wechat-minigame` 保留以兼容已经导入的项目，不需要切换为小游戏。

当前入口通过腾讯 [kbone](https://github.com/Tencent/kbone) 适配完整正式 HTML，包括双人基础/技能对战、38 名角色、多人 AI 比赛、设置、规则和战报；首页另有“真人联机”。原始 HTML、EXE 和 APK 不受此适配修改。

## 先验证离线游戏

在微信开发者工具打开本目录，点击“编译”。首次进入双人对战，先走完教程；试锻造、攻防、战报展开，再测试多人角色选择与开局。小程序组件与浏览器不同，仍需在开发者工具和真机验证布局、触摸、声音与战报图片导出。

不用重新导入，也不用开通云开发或提供 AppSecret。本机离线玩法不需要服务器。

已修复的适配问题：WXSS 不支持的 `:has` 和复杂 `:not` 选择器、动态角色选择框没有默认值、双人战报使用的 `insertAdjacentHTML` 缺失，以及表单按钮的默认提交行为。以上修复都在生成器中，下次生成会保留。

## 本地真人联机

1. 在仓库根目录双击 **启动联机测试.cmd**，保持窗口打开。
2. 小程序首页点“真人联机”，服务器填 `http://127.0.0.1:3238`，设置昵称、角色与队伍，创建房间。
3. 另一客户端使用相同服务器地址和六位房间号加入。至少两名真人可开局，空位由 AI 补齐，最多 12 人；按加入顺序分队。
4. 房主开始对局。每次先发动可用技能，再点“准备完成”；全员准备后选择招式。技能改变状态会清除准备，需要重新准备。
5. 帮接、帮闪、猜拳、审判、技能目标等选择由相应玩家本人响应。返回首页后，可从“真人联机→回到上次房间”恢复连接。

若开发者工具拒绝本地 HTTP 请求，在“详情→本地设置”勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”，仅用于本地调试。项目默认的域名校验配置没有被关闭。

手机与电脑同一 Wi-Fi 测试时，改用根目录 **启动局域网联机.cmd**，并填写窗口显示的电脑局域网地址。手机上的 `127.0.0.1` 指手机自己，不能填写该地址。真机调试/预览权限以测试号及开发者工具实际支持为准；如系统询问网络访问，可仅允许私人网络。不需要配置公网端口转发。

## 联机范围与限制

- 服务端直接复用 v2.5.8.2 的多人结算及全角色技能，统一裁判；客户端不提交伤害结果。普通出招先保密收齐，再结算。
- 38 角色的攻击/受击、开局主动操作、帮接归零、猜拳保密、12 人同步和重连已有自动测试；复杂角色组合仍需实战验收，尚不是正式公开运营版本。
- 当前是房间制多人玩法。客户端约每 1.2 秒获取一次状态，未添加排位、匹配、微信好友邀请或排行榜。
- 房间保存在服务器内存中；关闭服务器会结束所有房间。断线保留原座位并等待其重连，不会替真人自动作答。两小时无人访问的房间会清理；房主也可点击“结束房间”。
- 当前没有公网服务器、HTTPS 域名或微信正式发布配置。此步骤可先在本机/局域网做出来，公网运营另行处理，不把测试号等同于免费托管资格。
- 网页浏览器的文件下载改为战报图片预览，可长按保存；没有接入微信社交分享。

## 以后更新

仓库根目录双击 **生成微信小程序.cmd**：重新读取正式 HTML，生成项目，执行微信原生 WXSS/WXML 编译、适配启动、原生组件交互与双客户端联机检查。成功后回到开发者工具再点“编译”。

当前生成器和服务端固定读取 `合掌网页版-正式版本存档/合掌网页版v2.5.8.2.html`。升级正式版本时，需要同步修改 `tools/wechat-full/build.cjs` 与 `online-server/engine.mjs` 的源路径并核对抽取边界，不应仅重命名版本号。`source-manifest.json` 记录本次源文件的 SHA-256。

不要手改 `common/`、`pages/full/`、`pages/base.js`、`miniprogram_npm/` 或生成的应用入口。适配代码在 `tools/wechat-full/`，联机服务在 `online-server/`。原来的基础 Canvas 页面 `pages/index/` 保留为回退参考。

构建需要 Node.js、固定版本的构建依赖和本机微信开发者工具。脚本优先使用 PATH 中的 Node.js，也能找到当前电脑已有的运行环境。微信工具安装在其他目录时，设置 `WECHAT_DEVTOOLS` 环境变量。依赖版本锁定在 `tools/wechat-full/pnpm-lock.yaml`，已生成的项目不要求开发者工具再次“构建 npm”。

完整规则回归：`node --test tests/*.test.mjs`。原生组件交互检查会沿用真实 kbone 的点击、选择框变更与表单提交处理，再检查游戏结算；它不等同于真机屏幕验收。
